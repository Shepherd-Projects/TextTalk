All icons share the original 24x24 view box, 2-unit outline, round caps and
round joins. Native control icons use 22 logical pixels at 100% scale; the
primary microphone uses a 56-pixel circular metal inset.
Supplied rectangle and native font metrics scale geometry uniformly.
Modifications: SVG circular endpoint arcs converted to GDI+ center arcs;
SVG paths/rectangles embedded directly as native drawing operations.
Windows uses a generic Lucide window metaphor, not a Microsoft logo.
